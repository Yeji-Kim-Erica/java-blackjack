## 🧪 실험: 기능 추가 시 변경 범위 분석

### 📝 해볼 것

1. 1단계에서 구현한 블랙잭 코드를 준비
2. **베팅 기능**을 추가한다고 가정
3. 실제로 수정하지 않고, **어디를 수정해야 하는지 표시만**
4. 표시한 곳의 개수와 위치를 기록

### 🔎 관찰할 것

| 질문                  | 기록 |

| 수정이 필요한 파일 개수       |    |

| 수정 시 깨질 것 같은 테스트 개수 |    |
